# **App Name**: Firebase Flow

## Core Features:

- Auth UI: User authentication page with fields for email and password, along with options for login and signup.
- Auth Hooks: Simplified custom React hooks for Firebase authentication to handle user sign-in, sign-up, sign-out, and password reset functionalities.
- Route Guard: Route protection using Firebase authentication status, preventing unauthorized access to protected pages. Redirects to login if user is not authenticated.
- Folder structure suggestion tool: Use a tool that suggests the proper folder structure

## Style Guidelines:

- Primary color: Sky blue (#87CEEB) for a clean, trustworthy feel.
- Background color: Light gray (#F0F8FF) for a soft, neutral base.
- Accent color: Deep blue (#4682B4) to highlight important actions, like login or signup.
- Font pairing: 'Inter' (sans-serif) for both headlines and body text, for a modern and clean presentation.
- Simple, outline-style icons for authentication-related actions (lock, user, email).
- Clean, centered layout for the authentication form with enough spacing for readability.
- Subtle fade-in animations for form elements.
